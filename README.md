# 📈 Stock Market EDA (NSE/BSE)

Exploratory Data Analysis of major Indian stocks using Python and yfinance API. This project explores historical trends, daily returns, volatility, sector comparisons, and correlation insights.

## 📌 Objectives

- Analyze stock price trends
- Calculate daily returns and volatility
- Compare moving averages
- Generate correlation heatmaps
- Extract financial insights

## 📊 Tools Used

- Python (pandas, yfinance, matplotlib, seaborn, plotly)
- Jupyter Notebook
